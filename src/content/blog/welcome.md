Welcome! This is the very first post on my new blog, built with
[Astro](https://astro.build) and hosted for free on
[Cloudflare Pages](https://pages.cloudflare.com).

## Why this stack?

- **Fast** — Astro ships zero JavaScript by default, so pages load instantly.
- **Cheap** — Cloudflare Pages serves static files from a global CDN at no cost.
- **Simple** — Write posts in Markdown, push to Git, and it deploys automatically.

## What to expect

I'll be writing about whatever I'm learning and building. Posts are just
Markdown files in `src/content/blog/`, so adding a new one is as easy as
creating a file.

Here's a quick code sample to prove syntax highlighting works:

```ts
function greet(name: string): string {
  return `Hello, ${name}!`;
}

console.log(greet('world'));
```
